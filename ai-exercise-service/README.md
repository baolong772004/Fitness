# Exercise measurements and technique evaluation service

This service uses MediaPipe Pose Landmarker in video mode and OpenCV. The independent `technique-evaluation-2` engine separates measurements, reference standards, individual targets, and validated criterion decisions. The current standards are **drafts**; no exercise has Coach-validated technique verdicts enabled. Squat has experimental rep segmentation and eight measurement groups; five other exercise types expose projected measurements only. See [TECHNIQUE_IMPLEMENTATION.md](TECHNIQUE_IMPLEMENTATION.md) for actual capability, validation, and limits.

1. Install Python 3.11 or 3.12 and run `pip install -r requirements.txt`.
2. Download the official [Pose Landmarker Lite model](https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task) to `models/pose_landmarker_lite.task`, or set `POSE_MODEL_PATH`.
3. Set `AI_SERVICE_KEY` and `AI_SERVICE_URL=http://127.0.0.1:8001` in `backend/.env`.
4. On Windows, run `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run-local.ps1` from this directory. The script reads the private key from `backend/.env` and runs the local AI service. Alternatively, set the same `AI_SERVICE_KEY` in the service environment and run `uvicorn main:app --host 127.0.0.1 --port 8001`.
5. Deploy the pending Prisma migration separately with `npm run db:migrate`, then start the backend. Do not expose port 8001 publicly.

Run `python -m unittest discover -p 'test_*.py' -v` for all rule, registry, evaluation, release-gate and pipeline tests. For the Squat video matrix, install `requirements-dev.txt`, run `python diagnose_videos.py --build --run`, then `python diagnose_videos.py --report`. For the multi-exercise real clips run `python run_technique_smoke.py --run --report`. The reports are [evaluation/PIPELINE_DIAGNOSTICS.md](evaluation/PIPELINE_DIAGNOSTICS.md) and [evaluation/TECHNIQUE_SMOKE.md](evaluation/TECHNIQUE_SMOKE.md). A Coach-labeled collection is still needed for accuracy evaluation; no accuracy claim is made without it.

The backend sharing integration test requires `PT_TEST_DATABASE_URL` pointing to a separate migrated SQL Server database whose name contains `test`. Run it with `node --import tsx --test tests/exerciseAnalysis.integration.test.ts` from `backend`. Never point this variable at the production database. For a disposable local test database, run `node tests/run-exercise-isolated.mjs` from `backend`; it requires localhost SQL Server and database creation permission, migrates a newly generated test database and removes it afterward.

With the updated AI service already running, `node tests/run-exercise-isolated.mjs --with-real-ai --with-wallet` also verifies actual inference through the worker and the PT regression suite. It never migrates the application database. Standard review and release instructions are in [standards/README.md](standards/README.md) and [standards/RELEASE_PROCESS.md](standards/RELEASE_PROCESS.md). Historical results retain their standard snapshot/version and are not regraded automatically.

The backend keeps private uploaded videos for at most seven days. Analysis history (including sampled pose coordinates) and Coach feedback remain until the member deletes the analysis. Members can share the result with an active Coach while their PT relationship is valid, and must separately opt in to include the original video. Existing shares default to result-only. Video reads check current ownership/consent/relationship and expiry, support HTTP ranges, and use private/no-store caching. The Coach can leave a written confirmation or correction, and the member can revoke future access. Already downloaded content cannot be recalled. Uploads have configurable 24-hour limits (`AI_FORM_MEMBER_24H_LIMIT`, `AI_FORM_TRIAL_24H_LIMIT`, `AI_FORM_PT_24H_LIMIT`).

The Squat movement module `squat-observation-6` keeps the standing calibration and per-repetition checks from v5, decodes frames sequentially at their actual timestamps, and reports why frames and criteria were refused. See [DEBUG_REPORT.md](DEBUG_REPORT.md) for the earlier pipeline fixes, [SQUAT_V5.md](SQUAT_V5.md) for calibration and [SQUAT_V4.md](SQUAT_V4.md) for the original formulas. Those historical observation rules remain experimental; the independent technique engine now owns standard/approval decisions. Other exercise types have measurement previews, without validated segmentation or technique verdicts.
